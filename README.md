## EECS 281 — Data Structures and Algorithms

### 1. Priority Queue Implementations

**Focus: Advanced Data Structures and Algorithmic Efficiency**

Implemented custom priority queue data structures and explored their applications in computational simulations.

Key technical components:

- Binary heap and pairing heap implementations
- Generic programming using C++ templates
- Custom comparators and priority-based ordering
- Pointer-based data structures
- Dynamic memory management
- Time and space complexity analysis

Skills demonstrated: Data structure design, algorithm analysis, generic programming, and memory management.

### 2. Log Management System

**Focus: Information Retrieval and Efficient Data Processing**

Developed a C++ log management system for organizing, searching, and retrieving structured log entries.

Key technical components:

- Parsing and processing structured log records
- Sorting and organizing data
- Search and indexing operations
- Efficient data retrieval
- Command-line interaction
- Data structure selection for different operations

Skills demonstrated: Information retrieval, data processing, algorithm design, and computational efficiency.

### 3. Treasure Hunt

**Focus: Graph Traversal and Search Algorithms**

Developed a configurable search system for navigating multi-terrain environments and locating target destinations.

Key technical components:

- Breadth-first search (BFS)
- Depth-first search (DFS)
- Stack and queue-based traversal
- Path reconstruction
- Command-line argument processing
- Configurable search strategies

Skills demonstrated: Graph traversal, algorithm implementation, STL containers, and structured problem-solving.

## EECS 280 — Programming and Introductory Data Structures

### 4. Binary Search Tree & Map

**Focus: Recursive Data Structures and Generic Programming**

Implemented a binary search tree and map abstraction in C++, supporting ordered data storage and retrieval.

Key technical components:

- Binary search tree operations
- Recursive algorithms
- Generic programming using templates
- Pointer manipulation
- Dynamic memory management
- Map abstractions and ordered traversal

Skills demonstrated: Recursion, tree-based data structures, memory management, and abstraction.

### 5. Naive Bayes Text Classifier

**Focus: Machine Learning and Probabilistic Classification**

Implemented a probabilistic text classification system based on the Naive Bayes algorithm.

Key technical components:

- Text processing and feature extraction
- Word frequency analysis
- Probability estimation
- Log-probability calculations
- Model training and prediction
- Associative containers for data representation

Skills demonstrated: Statistical learning, probabilistic modeling, text processing, and machine learning implementation in C++.

### 6. Image Processing

**Focus: Computational Image Manipulation**

Developed matrix-based image processing functionality in C++.

Key technical components:

- Matrix representation and manipulation
- Pixel-level image processing
- Image transformation algorithms
- Array-based data structures
- Modular software design
- Testing and debugging

Skills demonstrated: Numerical computation, matrix operations, abstraction, and software testing.

### 7. Euchre Simulator

**Focus: Object-Oriented Software Development**

Developed a C++ simulation of the Euchre card game using object-oriented programming principles.

Key technical components:

- Class design and encapsulation
- Inheritance and polymorphism
- Card and player representations
- Game-state management
- Rule-based decision-making
- Modular program architecture

Skills demonstrated: Object-oriented programming, software architecture, abstraction, and simulation.
